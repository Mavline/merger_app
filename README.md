# Excel Tables Fusion

Browser tool for horizontal merges of two Excel files, vertical merges of multiple BOM files, and pivot tables. Each workflow provides a preview and Excel export.

Live app: https://excelm.replit.app/

Related acty.dev example: https://acty.dev/examples/excel-table-merging/

## Run locally

Prerequisites:

- Node.js.
- npm.

Commands:

```bash
npm install
npm start
```

Build:

```bash
npm run build
```
